05. Project Information

Design and implementation of a 4-bit Arithmetic Logic Unit using Verilog HDL, Vivado XSim simulation, a Python FastAPI backend and a web-based calculator interface.

Project objectives

  • Design a 4-bit ALU supporting eight arithmetic and logical operations.
  • Implement and simulate the RTL using AMD Vivado XSim.
  • Compare a conventional architecture with a shared arithmetic architecture.
  • Connect the Verilog simulation to a Python backend.
  • Provide a browser-based interface for ALU calculations and result inspection.
