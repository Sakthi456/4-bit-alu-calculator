How the ALU Works

  1. Two 4-bit operands are supplied through Input A and Input B.
  2. The 3-bit opcode determines the required ALU operation.
  3. The arithmetic or logic unit performs the selected operation.
  4. The result selection logic chooses the appropriate output.
  5. The ALU produces a 4-bit result and status flags.
